Seu espaço já está criado! Agora só falta provisionar (configurar billing).

## Execute este comando:

```bash
w3 space provision
```

## Quando perguntar sobre autorização:

1. Escolha **"Via Email"** (use as setas e ENTER)
2. Digite seu email quando solicitado
3. Você receberá um email de confirmação
4. Clique no link do email para confirmar

## Após confirmar o email:

O sistema está pronto! Para testar:

1. Acesse: http://localhost:5173/test-upload
2. Clique em "Choose File" e selecione um arquivo
3. Clique em "Upload Encrypted File"
4. O arquivo será criptografado e enviado ao Web3Storage

## Para ver seus arquivos:

```bash
w3 ls
```

Ou acesse: https://console.web3.storage/
