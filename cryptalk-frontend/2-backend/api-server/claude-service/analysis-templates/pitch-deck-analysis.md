# Pitch Deck Analysis Template

## Estrutura Recomendada

### Slides Essenciais
1. **Título/Capa** - Nome da empresa, logo, tagline
2. **Problema** - Qual problema você resolve?
3. **Solução** - Como você resolve esse problema?
4. **Mercado** - Tamanho do mercado e oportunidade
5. **Produto** - Demo ou explicação do produto
6. **Tração** - Evidências de progresso
7. **Modelo de Negócio** - Como você ganha dinheiro?
8. **Competição** - Análise competitiva
9. **Time** - Quem está executando?
10. **Financials** - Projeções financeiras
11. **Funding** - Quanto você precisa e como vai usar?
12. **Contato** - Informações para follow-up

## Critérios de Avaliação

### Clareza (1-10)
- Problema claramente definido
- Solução fácil de entender
- Linguagem simples e direta

### Mercado (1-10)
- Tamanho de mercado realista
- Segmentação clara
- Oportunidade quantificada

### Tração (1-10)
- Evidências de progresso
- Métricas relevantes
- Crescimento demonstrado

### Time (1-10)
- Experiência relevante
- Complementaridade de skills
- Track record

### Financials (1-10)
- Projeções realistas
- Unit economics claros
- Path to profitability

## Pontos de Atenção
- Muitos slides (máximo 15)
- Texto excessivo
- Projeções irrealistas
- Falta de evidências
- Time incompleto
