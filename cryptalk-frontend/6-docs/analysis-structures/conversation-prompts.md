# Prompts de Conversação para Análise de Documentos

## 1. Prompts de Inicialização

### 1.1 Detecção Automática de Tipo
```
Você enviou um documento para análise. Deixe-me identificar o tipo e preparar a análise apropriada.

[Após análise do documento]

Identifiquei que este é um [TIPO DE DOCUMENTO]. Vou usar nossa estrutura especializada para [TIPO] que analisa:
- [Aspecto 1]
- [Aspecto 2] 
- [Aspecto 3]
- [Aspecto 4]

Posso começar a análise completa ou você gostaria de focar em algum aspecto específico primeiro?
```

### 1.2 Confirmação de Escopo
```
Antes de iniciar a análise detalhada, gostaria de entender:

1. Qual é o contexto desta análise? (due diligence, planejamento estratégico, etc.)
2. Há algum aspecto específico que é mais importante para você?
3. Existe alguma informação adicional que deveria considerar?
4. Qual é o nível de detalhe desejado? (análise executiva ou deep dive)

Com essas informações, posso customizar a análise para ser mais útil.
```

## 3. Prompts de Análise Específica

### 3.1 Pitch Deck - Storytelling
```
Analisando o storytelling do pitch deck, vou avaliar:

📖 **Narrativa**: A história é clara e convincente?
🎯 **Problema/Solução**: O problema é real e a solução é diferenciada?
📊 **Dados**: Os dados suportam a narrativa?
🎨 **Apresentação**: O design e flow são eficazes?

Quer que eu analise slide por slide ou prefere uma avaliação geral primeiro?
```

### 3.2 Patente - Novidade
```
Para avaliar a novidade desta patente, vou examinar:

🔍 **Prior Art**: Que arte anterior foi considerada?
💡 **Diferenciação**: Quais são os elementos verdadeiramente novos?
⚖️ **Reivindicações**: As claims são bem fundamentadas?
🏭 **Aplicabilidade**: Há utilidade industrial clara?

Você tem acesso a alguma pesquisa adicional de prior art que deveria considerar?
```

### 3.3 Projeção Financeira - Premissas
```
Analisando as premissas financeiras, vou focar em:

📈 **Crescimento**: As taxas são realistas e sustentáveis?
💰 **Unit Economics**: CAC/LTV/Payback fazem sentido?
🔄 **Sazonalidade**: Há padrões temporais considerados?
⚡ **Sensibilidade**: Como mudanças impactam os resultados?

Há algum benchmark específico da indústria que deveria usar para comparação?
```

## 4. Prompts de Interação

### 4.1 Solicitação de Feedback
```
Completei a análise de [SEÇÃO/ASPECTO]. Antes de continuar, gostaria de validar:

Minha avaliação de [ASPECTO] como [AVALIAÇÃO] está alinhada com sua percepção?
Há algum contexto que mudaria essa avaliação?

Sua confirmação vai garantir que a análise final seja mais precisa.
```

### 4.2 Oferecimento de Comparação
```
Posso comparar [ASPECTO ANALISADO] com:

📊 **Benchmarks da indústria**: Como se compara ao mercado?
🏆 **Melhores práticas**: Quais são os padrões gold standard?
⚖️ **Casos similares**: Como outros casos se comportaram?
📈 **Evolução temporal**: Como isso mudou ao longo do tempo?

Qual tipo de comparação seria mais útil para você?
```

### 4.3 Exploração de Cenários
```
Baseado na análise, posso explorar alguns cenários:

🎯 **Cenário Base**: [Descrição do cenário atual]
📈 **Cenário Otimista**: [Se tudo der certo]
📉 **Cenário Pessimista**: [Se surgirem problemas]
🛠️ **Cenário de Mitigação**: [Com ações corretivas]

Qual cenário você gostaria de explorar primeiro?
```
