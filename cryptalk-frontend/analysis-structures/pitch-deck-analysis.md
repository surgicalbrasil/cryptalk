# Estrutura de Análise para Pitch Deck

## 1. Estrutura de Análise Completa

### 1.1 Análise Executiva
- **Resumo do Negócio**: Descrição clara e concisa do que a empresa faz
- **Proposta de Valor**: Como resolve o problema identificado
- **Modelo de Negócio**: Como a empresa gera receita
- **Estágio Atual**: MVP, tração inicial, growth, etc.

### 1.2 Análise de Mercado
- **TAM (Total Addressable Market)**: Tamanho total do mercado
- **SAM (Serviceable Addressable Market)**: Mercado alcançável
- **SOM (Serviceable Obtainable Market)**: Mercado capturável realisticamente
- **Tendências de Mercado**: Crescimento, mudanças regulatórias, tecnológicas
- **Timing**: Por que agora é o momento certo

### 1.3 Problema e Solução
- **Problema Identificado**:
  - Clareza na definição
  - Magnitude e urgência
  - Evidências e validação
- **Solução Proposta**:
  - Diferencial competitivo
  - Viabilidade técnica
  - Escalabilidade

### 1.4 Produto/Serviço
- **Funcionalidades Principais**: Core features
- **Roadmap de Produto**: Evolução planejada
- **Tecnologia**: Stack, propriedade intelectual
- **User Experience**: Interface, facilidade de uso

### 1.5 Modelo de Negócio
- **Fontes de Receita**: Principais streams
- **Precificação**: Estratégia e justificativa
- **Unit Economics**: CAC, LTV, margem de contribuição
- **Escalabilidade**: Potencial de crescimento

### 1.6 Go-to-Market
- **Estratégia de Entrada**: Como conquistar primeiros clientes
- **Canais de Distribuição**: Direto, indireto, digital
- **Marketing e Vendas**: Táticas e orçamento
- **Parcerias Estratégicas**: Potenciais e existentes

### 1.7 Análise Competitiva
- **Concorrentes Diretos**: Principais players
- **Concorrentes Indiretos**: Soluções alternativas
- **Vantagens Competitivas**: Barreiras de entrada
- **Posicionamento**: Como se diferencia

### 1.8 Tração e Métricas
- **KPIs Principais**: MRR, ARR, crescimento, churn
- **Clientes**: Quantidade, perfil, case studies
- **Partnerships**: Acordos fechados
- **Marcos Alcançados**: Principais achievements

### 1.9 Time
- **Fundadores**: Background, experiência relevante
- **Time Atual**: Competências, gaps
- **Advisors**: Mentores e conselheiros
- **Plano de Contratação**: Próximas posições críticas

### 1.10 Financeiro
- **Histórico**: Receitas e despesas até agora
- **Projeções**: 3-5 anos
- **Burn Rate**: Atual e projetado
- **Break-even**: Quando espera atingir

### 1.11 Investimento
- **Rodada Atual**: Valor buscado
- **Valuation**: Pre-money esperado
- **Use of Proceeds**: Como será usado o investimento
- **Rodadas Anteriores**: Histórico de captação

## 3. Prompts de Análise Estruturados

### 3.1 Análise Inicial
```
Ao analisar este pitch deck, considere:
1. A história está clara e convincente?
2. O problema é real e significativo?
3. A solução é inovadora e viável?
4. O mercado justifica o investimento?
5. O time tem capacidade de execução?
```

### 3.2 Análise de Mercado
```
Para avaliar o mercado:
1. Os números de TAM/SAM/SOM são realistas?
2. As fontes são confiáveis e atualizadas?
3. O crescimento projetado é sustentável?
4. Existem riscos regulatórios ou de mercado?
5. Como está o timing da oportunidade?
```

### 3.3 Análise Competitiva
```
Ao examinar a concorrência:
1. A análise competitiva é completa?
2. Os diferenciais são sustentáveis?
3. Existem barreiras de entrada reais?
4. Como é o posicionamento vs concorrentes?
5. Há espaço para coexistência no mercado?
```

### 3.4 Análise Financeira
```
Para os aspectos financeiros:
1. As projeções são conservadoras ou agressivas?
2. Os unit economics fazem sentido?
3. O burn rate é adequado ao estágio?
4. O uso dos recursos está bem definido?
5. A valorização proposta é justa?
```

## 5. Perguntas Sugeridas para Aprofundamento

### 5.1 Sobre o Mercado
- "Como vocês validaram o tamanho do mercado apresentado?"
- "Quais são as principais tendências que impulsionam este mercado?"
- "Como vocês veem a evolução da concorrência nos próximos 3 anos?"
- "Existem riscos regulatórios que devemos considerar?"

### 5.2 Sobre o Produto
- "Qual é o feedback mais comum dos usuários atuais?"
- "Como vocês priorizam o roadmap de produto?"
- "Quais são as principais barreiras técnicas para escalar?"
- "Como vocês protegem a propriedade intelectual?"

### 5.3 Sobre o Modelo de Negócio
- "Como vocês chegaram ao modelo de precificação atual?"
- "Qual é a estratégia para melhorar os unit economics?"
- "Como vocês planejam diversificar as fontes de receita?"
- "Qual é o caminho para profitabilidade?"

### 5.4 Sobre Tração
- "Qual é o perfil do cliente ideal validado até agora?"
- "Como tem evoluído o CAC nos últimos meses?"
- "Quais são os principais drivers de churn?"
- "Como vocês medem o sucesso do cliente?"

### 5.5 Sobre o Time
- "Quais são as próximas contratações críticas?"
- "Como vocês estruturam a cultura da empresa?"
- "Qual é a experiência prévia relevante dos fundadores?"
- "Como está estruturado o cap table atual?"

### 5.6 Sobre o Investimento
- "Como foi definida a valorização proposta?"
- "Qual é o runway com o investimento atual?"
- "Quais são os principais milestones para os próximos 18 meses?"
- "Como vocês veem as próximas rodadas de investimento?"

## 6. Red Flags Comuns

### 6.1 Mercado
- TAM irrealisticamente grande
- Falta de evidências sobre crescimento
- Timing questionável
- Subestimar concorrência

### 6.2 Produto
- Solução procurando problema
- Complexidade excessiva
- Falta de diferenciação clara
- Dependência tecnológica arriscada

### 6.3 Financeiro
- Projeções "hockey stick" sem base
- Burn rate desproporcional
- Unit economics negativos sem plano claro
- Valorização descolada da realidade

### 6.4 Time
- Falta de experiência relevante
- Turnover alto de fundadores
- Gaps críticos não endereçados
- Falta de skin in the game
